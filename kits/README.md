# Frameo Kits

The public SDK is in `packages/kit-sdk/src`. A Kit declares capabilities and uses `KitRegistry.register()` to stage all registrations. The registry enables the package only after the registrations match its manifest. Cleanup removes every capability in the package.

The first release ships a curated Seedance provider, three specialist agents, caption styling, and a product-film recipe. Declarative JSON packages contain agents and recipes and cannot execute code. Native JavaScript packages declare a relative `entry` in `kit.manifest.json` and export `register(registration)`. Native installation requires an explicit trust review showing origin, license, permissions and a content digest. A package is installed disabled; enabling it makes its declared roles and recipes available.

Native Kits run in a separate background process. It validates the reviewed manifest, package digest, dependency versions and registrations before publishing capabilities. The process has the same operating-system account permissions as the app: it isolates failures and is **not an OS sandbox for malicious code**. The host does not provide credentials, execute install scripts or run `npm install`. Authors supply compiled `.mjs`/`.js` modules and bundle relative dependencies; symlinks and `node_modules` directories are rejected. The `examples/caption-case` directory is an installable native example.

Agents discover capabilities through `capabilities_search`, inspect their schemas through `capabilities_describe`, and call enabled tools through `invoke_kit`. Specialist definitions list allowed tool IDs. Every tool input and output is validated with JSON Schema (Draft 7 or 2020-12); formats are annotations. Agents propose changes and cloud generations for review. Tools receive a bounded project snapshot, never the host database. Edit tools return the target sequence revision and commands; job tools return a plan. The host owns acceptance, budget reservations, generation submission and asset ingestion. The first release submits generated video through Seedance only; native provider declarations do not add paid submission routes.

Recipes bind inputs through JSON Pointers, declare predecessor steps, and retain separate reviews before execution and after results. Packages cannot contain API keys, private file paths, chat sessions or recipe run state.

To build the SDK independently, run `npm install` and `npm run build` in `packages/kit-sdk`. TypeScript Kit authors import contracts from `@frameo/kit-sdk`, compile their entry to JavaScript, and supply the resulting directory. The application does not invoke the author's build command.
